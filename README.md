# local-shuffle-windows

ローカルの動画フォルダをシャッフル再生するための Windows 向け軽量プレイヤー。
macOS 版 [SimpleMoview](../SimpleMoview) の Windows 移植で、操作キーを **YouTube と互換**にしてある。

## 起動

初回:
```
start.bat
```
(自動で `npm install` → `npm start`)

2 回目以降は `start.bat` または `npm start` でそのまま起動。

## 機能

- フォルダ内の動画を一覧して順次再生(サブフォルダも再帰的にスキャン)
- 動画クリックで再生/一時停止、ダブルクリックでフルスクリーン
- シャッフル ON/OFF トグル
- 動画終了時に自動で次へ
- 「前へ」は再生履歴スタックから取り出す(直前に観た動画に戻る)
- 前回開いていたフォルダを起動時に自動復元
- 音量・ミュート・シャッフル状態を永続化
- 設定画面でショートカットモード切替・ReplayGain(動画間音量差の自動補正)切替
- ボスキー(`W` 押下中)・キューパネル(`Q` でにゅるん)・倍速制御・プロパティ表示
- 起動時 & 定期的(6時間ごと)に GitHub のリリースを確認し、新しいバージョンがあれば画面上部にバナーで通知(設定でオフ可)

対応拡張子: `.mp4` `.m4v` `.mov` `.mkv` `.webm` `.avi` `.wmv`

## キーボードショートカット

設定画面(`⚙` ボタン)で **YouTube 互換モード** と **シンプルモード** を切替可能。

### 共通(両モード)

| キー | 動作 |
|---|---|
| `Space` / `K` | 再生/一時停止(動画クリックでも可) |
| `←` / `→` | 5 秒戻る/進む |
| `J` / `L` | 10 秒戻る/進む |
| `0` ~ `9` | 0% ~ 90% 地点へジャンプ |
| `D` / `S` | 再生速度 +0.1x / -0.1x |
| `↑` / `↓` | 音量 +5% / -5% |
| `M` | ミュート |
| `F` | フルスクリーン (ダブルクリックでも可) |
| `Shift+N` / `Shift+B` | 次/前の動画 |
| `Shift+>` (`Shift+.`) / `Shift+<` (`Shift+,`) | 再生速度 ±0.25x(0.25x ~ 3.0x) |
| `R` | シャッフル切替 |
| `I` | プロパティ(ファイル/コーデック/撮影端末情報)をトグル表示 |
| `O` | フォルダを開く |
| `Q` | キュー(次に何が来るか)パネルをトグル |
| `W` | **ボスキー**(画面真っ黒・動画停止・音声ミュート)。設定で「トグル(押すごとに切替)」/「ホールド(押している間だけ)」を選択可、デフォルト トグル |
| `Esc` | モーダル/キュー/フルスクリーンを段階的に閉じる |

### シンプルモード追加分

| キー | 動作 |
|---|---|
| `N` / `B` | 次/前の動画(Shift 不要) |
| `.` / `,` | 再生速度 ±0.25x(Shift 不要) |

倍速バッジをクリックすると 1.00x にリセット。

## 自動アップデート確認

起動から数秒後、および 6 時間ごとに GitHub Releases の最新版を確認する。
現在のバージョンより新しいタグが公開されていれば、画面上部に通知バナーを表示し、
**ダウンロード** ボタンで配布ページ(またはポータブル `.exe` のアセット)を既定のブラウザで開く。

- ポータブル版のため、起動中の `.exe` を自動で置き換える挙動は行わない(ダウンロード後に手動で差し替え)。
- 確認のオン/オフは設定画面(`⚙`)の `[ UPDATES ]` から切替可能(デフォルト オン)。`今すぐ確認` で即時チェックもできる。
- ネットワークがオフライン等で確認に失敗した場合は黙って無視する(再生をブロックしない)。

## コーデックについて

再生は Chromium 内蔵デコーダで行うため、対応コーデックには制限がある:

- **問題なく再生**: H.264 (mp4/mov/m4v) / VP9 / AV1 / WebM
- **環境依存**: HEVC (H.265)、MKV 内部のコーデック次第
- **再生不可になりがち**: 古い AVI/WMV(コーデック非対応)

再生できないファイルがあれば MP4 (H.264) に再エンコードしてください。

## ポータブル exe のビルド

```
npm install
npm run build
```

`dist\LocalShuffle-0.1.0-portable.exe` が生成される。これ単体をどこに置いても起動できる(設定は `%APPDATA%\local-shuffle-windows\config.json` に保存される)。
初回ビルド時は electron-builder が Electron バイナリと `app-builder` をダウンロードするため数百 MB かかる点に注意。
